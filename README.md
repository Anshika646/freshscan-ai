# FreshScan AI — Fruit Freshness Detection

An end-to-end machine learning application for optical fruit freshness classification built with **TensorFlow / Keras (MobileNetV2 transfer learning)**, **FastAPI**, **React 19 + TypeScript**, and **Express**, configured for GitHub (`FreshScan-AI`) and **Google Cloud Run** deployment.

> **Food Safety Disclaimer**: Visual classification detects external peel discoloration, bruising, and surface mold only. Image predictions cannot detect internal core rot, bacterial pathogens (*Salmonella*, *E. coli*, *Listeria*), mycotoxins, or chemical residue. Never rely solely on an optical prediction to guarantee food safety.

## 3. Data Preprocessing & Leakage Prevention Decisions

1. **Strict Image Validation**: Rejects empty files, unsupported extensions/MIME types, truncated byte streams (`ImageFile.LOAD_TRUNCATED_IMAGES = False`), and sub-`16x16` thumbnails.
2. **White-Background Alpha Compositing**: RGBA/transparent PNGs are composited onto a `#FFFFFF` canvas prior to 3-channel `RGB` conversion so transparent backgrounds do not turn into `0,0,0` black borders that mimic necrotic tissue.
3. **Exact & Perceptual Deduplication Before Splitting**:
   - Exact byte duplicates (`SHA-256`) are removed prior to dataset partitioning.
   - Near-duplicate / re-compressed captures sharing an identical 64-bit difference hash (`dHash`) are grouped into atomic clusters assigned together to a single split (`train`, `val`, or `test`), guaranteeing **zero cross-split leakage**.
4. **Stratified 70% / 15% / 15% Partitioning**: Preserves class proportions across training, validation, and held-out test splits (`seed=42`).
5. **Color-Preserving Training Augmentation**: Horizontal flips, `±8%` rotation, `±10%` zoom, and `±10%` contrast jitter are applied **exclusively to training batches**. Hue rotation is intentionally excluded because surface color is biologically diagnostic of oxidation and mold.
6. **Class Imbalance Mitigation**: Inverse-frequency balanced class weights (`compute_class_weight('balanced')`) are computed strictly from training split labels.

## 4. Local Setup, Training, Evaluation & Testing

### A. Install Dependencies

```bash
python3 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install -r requirements.txt
npm install
```

### B. Train the MobileNetV2 Model

```bash
# Default: fetches 60 raw photographs per class (960 total across 16 classes); pass --max-per-class 200 for all 3,200
.venv/bin/python train_model.py --max-per-class 60 --stage1-epochs 7 --stage2-epochs 6 --batch-size 32 --seed 42
```

### C. Evaluate on the Held-Out Test Set

```bash
.venv/bin/python evaluate_model.py
```

### D. Run Automated Tests

```bash
.venv/bin/pytest -v
```

### E. Run the Full-Stack Application Locally

```bash
# Development mode (starts Express on :3000 + supervises FastAPI TensorFlow server on :8050)
npm run dev

# Production build & start
npm run build
NODE_ENV=production npm start
```

## 5. GitHub Sync (`FreshScan-AI`) & Google Cloud Run Deployment

### Pushing to GitHub

1. **From CLI**:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial release: FreshScan AI end-to-end fruit freshness ML pipeline"
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/FreshScan-AI.git
   git push -u origin main
   ```
2. **From the In-App GitHub OAuth Panel**:
   Configure `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` in `.env` / platform secrets with callback `/auth/callback`, open the **GitHub & Deploy** tab, authorize via popup, and click **Create & Push to GitHub (`FreshScan-AI`)**.

### Deploying to Google Cloud Run

```bash
gcloud run deploy freshscan-ai \
  --source . \
  --region asia-east1 \
  --memory 2Gi \
  --cpu 2 \
  --port 8080 \
  --allow-unauthenticated
```
